# Ten-minute Loom outline

Record only after real results and public endpoints exist. Do not narrate planned
experiments as completed findings. Required length is 8–12 minutes.

0:00–1:00: professional task and deliberately narrow fictional authority; why this
is checkable and why actual payroll claims are outside scope.

1:00–4:30: show rules and citations, exact verifier, field partial credit, hard
trap/abstention gates, weights, adversarial baselines, constrained judge reliability
and rule-set fidelity audit. Explain decisions, not merely UI controls.

4:30–5:45: read a real failed model transcript aloud for at least a minute. Identify
the deciding clause, what the reward marked, and what the failure teaches.

5:45–7:30: five actual RL curves, frozen-reference proof, beta trade-off,
held-out before/after, group degeneracy, gaming found or search performed.

7:30–9:00: fetch Tier2/3 live tasks, submit an external answer, show score,
component clauses and persisted run without this laptop hosting the service.

9:00–10:00: transfer ranking finding, real limitations/spend, clean reproduction,
and next two days' highest-value work. Verify links before recording.
